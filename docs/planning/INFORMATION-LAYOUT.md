## 3. Decisions

**N-D1 — does `.planning/` move to `docs/planning/`?** The shared rule puts plans in flight in
`docs/planning/`. But here `.planning/` is not only GSD's state: it holds the research the art
pipeline reads from and writes into, and three build files exclude it by name. Moving it
means rewriting script paths, the image's ignore rules and CI's `paths-ignore` — a change to
what the build does, for a directory with no plan in flight. (a) **Keep it**, named in
AGENTS.md as this repo's archive and art work area, the documented exception (agent-config
keeps `proposals/` on the same reasoning); (b) move it, with the build changes. **Recommend
(a).** A new plan, when the game is picked up again, goes in `docs/planning/`.
